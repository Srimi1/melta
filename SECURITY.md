# Security Policy

## Supported versions

Only the latest release receives fixes.

## Reporting a vulnerability

Please do not open a public issue for security problems. Use
[GitHub private vulnerability reporting](https://github.com/Srimi1/melta/security/advisories/new)
instead. You will get a reply within a few days.

## Scope notes

Melta draws an overlay window, so anything that could make that window touchable, read screen content,
or be abused by another app is in scope.
